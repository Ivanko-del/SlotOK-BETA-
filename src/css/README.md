# src/css — вихідні шматки `style.css`

`style.css` у корені **згенерований**: `npm run build:css` склеює ці файли в
порядку номерів (пізніші перебивають ранні за однакової специфічності).
Система й правила — `DESIGN_SYSTEM.md` у корені.

| Файл | Що всередині |
|---|---|
| 00-tokens | дизайн-токени, темна/світла тема, акценти, псевдоніми старих змінних |
| 01-base | скидання, типографіка, поля, фокус, анімації, reduced-motion |
| 02-components | кнопки, поля, перемикачі, таби, чипи, картки, бейджі, списки, таблиці, тости, модалки, іконки |
| 03-shell | шапка, навігація (нижня / бічна), контейнер, сплеш, брейкпоїнти |
| 05-icons | **згенеровано** `npm run build:icons` з `src/icons/icons.js` |
| 50-legacy | старі правила екранів/ігор, переведені на токени; поступово розбираються |
| 60-home … 66-admin | екрани в новій мові: Головна, лоббі, Каса/Профіль, Налаштування, вхід, ігри, адмінка |
| 71-tables | гральні карти, стіл, поле Лудо |
| 70-mass | Бінго, Вікторина-баттл, Королівська битва |
| 69-live | спільні колеса й Краш наживо |
| 68-rooms | лобі онлайн-кімнат, Сапер, Морський бій |
| 67-games-3d | нові 3D-ігри (Plinko 3D, Колесо 3D, Кубики, Слот 5×3, Три в ряд) |
